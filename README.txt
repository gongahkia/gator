Gator is a desktop personal agent for ongoing work.

It gets smarter as it learns more about you.

Remote Work supervision and explicitly authorized external tmux access are
optional supporting capabilities. Gator does not require a particular terminal,
a phone, tmux, or Onibi. See docs/EXECUTION-TARGETS-T4.5.md for the final scope.
