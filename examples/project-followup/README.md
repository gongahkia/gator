# Project follow-up starter

This is synthetic test material for the [pilot procedure](../../docs/PROJECT_FOLLOWUP_PILOT.md).
Select only `source` (or a copy of it) as the workspace. The sibling `changes`
directory contains future versions and must remain outside that workspace.

Start Gator, choose a model, and open `/followup new`. The form, review, and
health panel guide the same workflow used for a real bounded project. Copy one
future version to the workspace's `project.md` at each replay step. Review
drafts, quiet outcomes, and source support before recording human judgments.
