# Support

Use GitHub issues for reproducible bugs and feature requests. For bugs, use the [bug-report template](.github/ISSUE_TEMPLATE/bug_report.md) and follow [diagnostic collection](docs/DIAGNOSTICS.md). Include:

- Neovim version, Gator commit/version, and operating system
- provider CLI/version and the relevant [support-matrix](docs/PROVIDERS.md) row
- `:GatorHealth` output with secrets removed and a reviewed `:GatorExportDiagnostics` report when it helps
- minimal reproduction steps, expected behavior, and actual behavior

Provider account, billing, model, and authentication problems remain with the provider. Do not post credentials, private prompts, or unredacted transcripts. See [SECURITY.md](SECURITY.md) for vulnerabilities.
